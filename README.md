### 🔭 En qué estoy hoy

- 🗣️ **IA local de punta a punta**: tótem de self-checkout **por voz** para fast food — Whisper (STT) + LLM local vía Ollama + Piper (TTS), **sin internet ni costo por pedido**.
- 🏧 **Kiosco de depósito bancario self-service** (C#/.NET): app de depósito, core de conciliación y adaptadores XFS para hardware de conteo de billetes.
- 🤖 **Bots de soporte en producción** (WhatsApp): motor modular con flujos JSON, perfiles, reportería y métricas — atendiendo clientes reales todos los días.
- 🔌 **Hardware propio**: drivers y firmware ESP32 (contadoras de billetes, sensores biométricos, control de motores), integración serial/UART/MQTT.
- ⛓️ **Web3 aplicado**: contratos Solidity con casos concretos ([KipuBankV4](https://github.com/JuanMoisio/KipuBankV4) — banco on-chain iterado en 4 versiones, testeado con Hardhat).
